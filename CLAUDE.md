## What This Is

A React/TypeScript web app for querying and visualizing personal Letterboxd film data enriched with TMDB metadata. Deployed at `hanielbarbosa.com/filminhos/`. It loads a ~12MB `master.json` (shipped as `public/master.zip`, extracted client-side via JSZip) and provides filtering, sorting, list management, and year-over-year watching statistics.

## Common Commands

```bash
npm start              # Dev server on port 3000
npm run build          # Production build → /build/

# Deploy (builds, uploads to Hostinger, generates indexes)
./upload.sh            # Full build + deploy
./upload.sh --no-build # Deploy without rebuilding

# Generate static pages (called by upload.sh, but can run standalone)
./index.py lists/      # Generate lists/index.html directory listing
python3 directors.py   # Generate directors/index.html from public/master.json
python3 clube.py       # Generate clube/index.html from clube.md (film club)
```

## Architecture

**Stack:** React 18 + TypeScript (Create React App), Chart.js for bar charts, JSZip for client-side zip extraction.

**Data flow:**
```
public/master.zip → JSZip extracts → master.json (in-memory)
                                          ↓
                    movies.service.ts (filter/sort) → Catalog grid display
```

URL parameters drive initial state: `?title=`, `?director=`, `?list=listname`, `?ids=id1;id2`, `?year=`, `?rating=`, `?genre=`, `?tags=`, etc.

**Key source files:**

- `src/App.tsx` — Main component. Loads master.zip, parses URL params, manages app state, renders Search + Catalog + year chart.
- `src/services/movies.service.ts` — Core business logic (~800 lines). `getMovies()` applies filters via `filterStatic()` (title/director/genre/year/runtime/country/studio) and `filterDiary()` (watch date/rating/tags/rewatch). `getAvailable()` queries TMDB API for streaming providers.
- `src/services/context.tsx` — React Context for global state (master data, filtered movies, search params, loading state).
- `src/components/Search/Search.tsx` — Search form with text, numeric, date, and checkbox filters. Supports list import/export as JSON.
- `src/components/Catalog/Catalog.tsx` — Movie grid with poster cards, selection, reordering, and metadata display.

**Python utilities (not browser-side):**

- `index.py` — Generates `lists/index.html` with clickable directory listings linking back to the app via `?list=` params.
- `directors.py` — Reads `public/master.json`, groups films by director, generates `directors/index.html` with alphabetical director index.
- `clube.py` — Reads `clube.md` (markdown: one `## <date>` section per film club meeting, `<title> (<year>)` lines for the suggestions, `*` marking the pick, free markdown after) and generates `clube/index.html`. Posters and directors come from TMDB, film links from Letterboxd; both cached in `clube.cache.json`.

**Data format (`master.json`):** Array of movie objects with fields: `id`, `tmdbId`, `title`, `year`, `rating`, `runtime`, `directors[]`, `writers[]`, `actors[]`, `genres[]`, `countries`, `studios[]`, `tags[]`, `watched` (date), `picture` (TMDB poster URL), `collection`, `views`, `available` (streaming providers).

**Lists (`lists/*.json`):** JSON arrays of movie IDs. Loaded via `?list=filename` URL param. Used for curated best-of-year lists, director filmographies, etc.

**Year reviews (`year-review/`):** Static HTML pages (`2023.html`, `2024.html`, `2025.html`) with annual watching summaries, styled by `review.css`.

## Deployment

Hosted on Hostinger at `~/public_html/filminhos/`. `upload.sh` orchestrates: build → rsync `build/` → extract master.zip → generate list/director indexes → rsync `lists/` and `directors/`.

## Data Dependency

`public/master.zip` (containing `master.json`) is generated by the parent project (`/home/hbarbosa/letterboxd/`) via `process.py --json`. The TMDB API key for streaming availability queries is stored in the `REACT_APP_API_KEY` environment variable.
